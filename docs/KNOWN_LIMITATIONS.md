## 功能限制

1. **独立可访问界面待建**：当前已有可加载的项目级 Skill、`src/core/` 决定权护栏、读屏友好命令行演示与 fixture 自动测试；图形界面、WorkBuddy 真实适配和端到端复测仍待 P1.2 建立。Skill 结构校验与本地测试不等于 WorkBuddy 端到端实测通过
2. **状态变更采用引导模式**：7 项状态变更工具均为 `GUIDE_ONLY`，本项目没有真实执行证据；下单、取消、地址保存、抽奖、自动领券、积分兑换与活动订单由用户在官方渠道完成
3. **手语输入不可用**：S1 实验未开始——无合法模型、无词表、无手语使用者共创（BLOCKED）；G0/S1/S2 三层能力分别命名，不混称
4. **候选生成只完成后半段**：三态约束、排序、过滤和预算检查已经编码；模糊表达（"夹鸡肉的"）到真实菜单候选的上游生成与 MCP 适配尚未编码

7. **输出契约缺失**：35 项定义均未提供 `outputSchema` 与 MCP `annotations`；解析必须依赖当前真实返回，结构变化时保留 `UNKNOWN`

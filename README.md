# 慢慢点（ManManDian）

> 麦当劳无障碍自主点餐 Skill —— 不催你，不替你决定。
> 本项目为「麦当劳程序员创意开发大赛」独立开发的参赛作品，**非麦当劳官方产品**。

## 项目定位

「慢慢点」把用户自己的表达——说得清的、说不清的——转化成基于麦当劳当前门店真实菜单、可理解的餐品选择与价格，再让用户以适合自己的方式修改和确认。

不是替特殊人群决定吃什么，而是帮用户完成五件事：

1. 说清或选出自己想吃的东西，即使不知道商品名
2. 看懂或听懂套餐里有什么、每样有多少、总共花多少钱
3. 不因优惠、误触或系统猜测而多买、多花
4. 不满意就改，不方便就换一种输入方式，不必重新开始
5. 确认什么就只执行什么；出了问题知道现在是什么状态、下一步怎么办

## 目标用户

不熟悉数字点餐的人、老年用户、阅读或表达不便者、盲人及低视力用户、聋人及听障用户、言语沟通不便者、精细动作不便者，以及噪声环境、临时不方便开口或单手操作的普通用户。**输入方式不同，决定权相同。**

## 安装与配置

1. 申请麦当劳 MCP Token：<https://open.mcd.cn/mcp>（登录 → 控制台 → 激活）
2. 将 `mcp-config.example.json` 的内容配置到你的 MCP 客户端，把 `${MCD_MCP_TOKEN}` 替换为真实 Token。**不要把真实 Token 提交到任何仓库**
3. 启用 mcd-mcp 连接器

## 使用示例

- 「两个人，三十元以内，想要夹鸡肉的，不要辣」→ 保存人数与预算 → 确认门店 → 基于真实菜单给出最多 3 个候选（未知辣度不当作不辣）→ 修改 → 真实核价
- 不方便开口：全程文字选择，生成标注「未下单」的沟通卡，店员可在同一设备文字回复
- 改主意：改一项只改一项，旧确认失效并重新核价，不清空其他选择

## 个人与门店价值

- 个人：自主完成任务、理解总价、按原意选择、可以改、可以退出。指标设计见主提示词第 18 节；**收益未经实测，不预填成绩**
- 门店：结构化交接卡减少需求遗漏、误解和重复确认。首版不要求店员安装后台，不接入门店收银/叫号系统

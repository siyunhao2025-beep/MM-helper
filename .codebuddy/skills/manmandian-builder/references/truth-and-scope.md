# 真相与边界（truth-and-scope）

> 依据主提示词 v1.0 第 0.1、1、3、7、8、10、12 节整理。

## 事实分层（每次对外声明必须标注来源类型）

| 类型 | 含义 |
|---|---|
| USER_PROVIDED | 用户明确提供的信息，原样保留上下文，不自动扩展授权 |
| DOC_CONFIRMED | 实际阅读的一手文档支持（不等于账户可用） |
| TOOL_OBSERVED | 真实工具返回（记录调用范围与时间） |
| TEST_OBSERVED | 实际执行的测试结果（区分环境、设备、数据与覆盖范围） |
| DESIGN_PROPOSAL | 本项目的设计或开发建议（不写成用户已批准的事实） |
| ASSUMPTION | 有待验证的假设（不进入高影响执行依据） |
| UNKNOWN | 当前不知道（保留未知并给出核验动作） |

## 范围锁定

- **做**：单用户、本地、到店取餐优先。确认门店/方式 → 真实菜单 → 详情/套餐组成 → 首屏≤3 候选（保留"看看其他选择"）→ 用户修改 → 真实核价 → 明确未下单沟通卡
- **P2 后且需授权**：受保护创建订单、官方付款、真实订单查询
- **永不**：猜辣度/配料/过敏适宜性；偷偷放宽预算；为优惠加购；默认领取会员/积分消耗；盲人道路导航；假装发送到门店系统

## 无障碍边界

- 所有入口共享同一草稿；询问"怎样操作方便"，不登记残疾身份、不推断病情
- 朗读是可选增强，不替代读屏；语义控件/键盘可达/状态可读是本体
- 精细动作：拖拽/长按/双击必须有普通点击/键盘替代；无催促倒计时
- 聋人/言语不便：全程文字 + 双向同设备沟通卡；拒麦也能完成
- 手语三层：G0 通用手势快捷键 / S1 限定词汇实验 / S2 研究方向——不得混称；相机默认关闭、退出停流、原始素材默认不保存；数量、否定、交易意图不直接触发下单

## 交易安全

- 分层：原始表达 → 解释候选 → 用户确认 → 官方事实 → 报价快照 → 订单回执
- 确认绑定：门店/方式/商品/数量/选项/优惠/总额/意图标识，变更即失效
- 创建超时 → UNKNOWN 先核验，不重下；无可靠订单标识不猜编号
- 创建 ≠ 付款 ≠ 可取餐；取消 ≠ 已退款
- 独立网页不能自动继承 WorkBuddy 工具权限；无法验证安全写入则只读

## 反幻觉红线

不得出现的替代关系：文档列出工具 ≠ 账户有权限；文件存在 ≠ 功能完成；fixture ≠ live；截图 ≠ 读屏实测；检测手势 ≠ 理解中国手语；下单返回 ≠ 已付款；状态文档写"完成" ≠ 存在证据。
